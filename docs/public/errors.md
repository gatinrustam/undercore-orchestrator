# Ошибки и повтор запросов

Прикладные ошибки возвращают `{"detail":"machine_readable_code"}`. Полный
[каталог](../../contracts/errors.json) содержит возможные HTTP-статусы; наличие
кода в каталоге не означает, что его возвращает каждый маршрут.

| Ситуация | Действие backend |
|---|---|
| 401 `unauthorized` | Исправить служебную авторизацию; не просить пароль пользователя VPN |
| 404 `not_found` | Проверить пару connection_id/device_id; не раскрывать чужое назначение |
| 422 `invalid_request` | Исправить запрос; неизменный запрос не повторять автоматически |
| 422 `unsupported_format`, `qr_unavailable` | Использовать возможности адаптера; не обрезать конфиг для QR |
| 409 `client_upgrade_required` | Проверить возможности клиента; не выдавать ему неизвестный формат |
| 410 `access_unavailable`, `grant_expired` | Проверить срок и отзыв; повтор не заменяет выдачу права backend |
| 429 `recovery_cooldown` | Выдержать паузу политики; не менять device_id или ключ ради обхода |
| 503 `lease_waiting` | Продолжить ту же операцию/ревизию после ожидания; не создавать новое назначение |
| 503 недоступного узла/процесса | Ограниченные повторы с задержкой и общим дедлайном; сообщить оператору при исчерпании |
| Несовпадение server identity, владельца или ревизии | Сверить состояние; не обходить проверки и не считать это пустым результатом |
| Таймаут без ответа | Результат неизвестен. Повторить исходную операцию со стабильной идентичностью |

Не все 409/503 допускают одинаковые повторы. Сверяйте машинный код и контекст
операции. Для первоначального create стабильность задаёт device_id, для renew и
switch — ключ операции, для recover — expected_revision. Политика backend должна
иметь предел попыток и времени. Интервал systemd worker не является рекомендацией
частоты клиентских запросов.

Неизвестный код ошибки сохраняйте как безопасные метаданные вместе с HTTP-статусом
и названием операции. Не записывайте токены, конфигурации и необработанные тела
ответов. Ошибка reverse proxy может иметь другое тело: сначала проверяйте статус
и Content-Type, затем разбирайте JSON. Ошибки маршрутизации/параметров FastAPI также
могут отличаться от прикладного envelope.
