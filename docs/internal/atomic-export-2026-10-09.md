В staging rollout версия 0.3.1 откачена из-за фактического HTTP 405/Allow: POST
старого агента; 0.3.2 учитывает его отдельно от прочих ошибок. Новый тест использует
реальный старый FastAPI-router. Исправленный кандидат проверен с реальным агентом
до повторного выпуска. Версия 0.3.1 как GitHub release не публиковалась.

1 HTTP и 1 reconcile; старый fallback — 5 HTTP (включая проверку нового маршрута),
4 reconcile. Временный доступ для приёмки отозван после сравнения.
