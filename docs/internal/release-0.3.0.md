# Проверка и выпуск 0.3.0

08.10.2026 опубликован тег v0.3.0 (`f99380c129462f5e896e90659ac732ac346c3920`).
98 тестов, контракты, каталог ошибок, Ruff и release CI прошли.

На чистой Ubuntu 24.04 проверены установка с umask 077, systemd start/restart/stop,
health, приватные права и резервная копия. Выявленная зависимость прав кода от umask
исправлена до публикации. Lifecycle проверялся на нативном Linux ARM, поскольку
эмуляция x86 в Docker Desktop не запускала системный journald. Переход с точного
релиза 0.2.0 на 0.3.0 сохранил настройки и SQLite. Production Linux x86 успешно
обновлён штатным updater; назначения и реестр совпали до/после, агенты доступны,
lease/recovery timers активны. Административный HTTP API возвращает 401.

Оператор управляет узлами локальным CLI. Авторизация пользователей и бизнес-права
остаются ответственностью вызывающего backend. Клиентские API v1/v2 сохранены.
Рабочие настройки, ключи, журналы и backup не входят в репозиторий или release asset.
